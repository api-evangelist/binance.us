# Binance.US

> Binance.US, operated by BAM Trading Services, Inc., is a U.S.-regulated digital asset marketplace for spot
> trading, staking, OTC and custodial services. Its developer program exposes a signed REST API at
> api.binance.us, a functionally equivalent WebSocket API at ws-api.binance.us, and real-time WebSocket market
> data and user data streams at stream.binance.us. Authentication is API key plus HMAC SHA-256 request
> signing (X-MBX-APIKEY header + signature parameter). There is no OpenAPI document, no OAuth surface and no
> first-party SDK.

Generated by the API Evangelist enrichment pipeline on 2026-08-07. Binance.US does not publish an llms.txt of
its own; this file is generated from the catalog profile and the artifacts in this repository.

## APIs

- [Binance.US REST API](https://docs.binance.us/#rest-api): Base https://api.binance.us. Exchange and system
  information, market and trade data, user account data, sub-accounts, spot order management (including OCO
  and cancel-replace), OTC quoting, wallet deposits/withdrawals, dust conversion, referrals, staking,
  Custodial Solution, Credit Line and API Partner endpoints. Paths under /api/v3, /sapi/v1 and /wapi/v3.
- [Binance.US WebSocket API](https://docs.binance.us/#websocket-api): wss://ws-api.binance.us/ws-api/v3.
  Request/response over WebSocket, functionally equivalent to the REST API, lower latency.
- [Binance.US WebSocket Streams](https://docs.binance.us/#websocket-streams): wss://stream.binance.us:9443.
  Real-time market data streams (aggTrade, trade, kline, ticker, miniTicker, rolling window, bookTicker,
  partial depth, diff depth) and user data streams (outboundAccountPosition, balanceUpdate, executionReport).
